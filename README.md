# CakeFast AI — Leitura Inteligente de Cupons Fiscais

Projeto experimental de Inteligência Artificial desenvolvido para interpretar imagens de cupons fiscais e transformar informações presentes nesses documentos em dados estruturados.

A solução utiliza a API da OpenAI para analisar imagens JPEG e identificar automaticamente informações relevantes das compras.

## 🎯 Objetivo

Desenvolver uma ferramenta capaz de automatizar a leitura de comprovantes fiscais, reduzindo o trabalho manual de digitação e facilitando o registro de despesas.

O projeto poderá futuramente ser integrado ao sistema financeiro da Cake Fast.

## ✅ Funcionalidades já demonstradas

- Processamento de imagens JPEG de cupons fiscais.
- Identificação da data de emissão.
- Reconhecimento do nome do estabelecimento emissor.
- Extração do valor total da compra.

## 🔧 Em desenvolvimento

- Aprimoramento da precisão na identificação dos dados.
- Otimização das consultas à API da OpenAI.
- Redução do consumo de tokens e dos custos de processamento.
- Organização dos dados extraídos para utilização em outros sistemas.

## 🚀 Visão futura

Integrar a tecnologia ao Controle_Cake, permitindo que uma imagem de cupom fiscal seja utilizada como ponto de partida para o registro de uma compra ou despesa.

## 🛠️ Tecnologias

- OpenAI API
- Inteligência Artificial
- Processamento de imagens
- Extração estruturada de informações

## 📌 Status

Protótipo funcional em fase de aprimoramento.
